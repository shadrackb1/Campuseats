# CampusEats AI

Voice-first food budget assistant for university students. Menus, meal plans, and campus delivery ideas that fit a student budget.

## What it does

- Voice agent for hands-free meal questions (Gemini Live)
- Chat bot for budget and menu help
- Meal planner tuned to budget, location, and cooking tools
- Vision assistant for photo-based food checks
- Preferences for daily budget, diet, and kitchen access

## Stack

React, TypeScript, Vite, Tailwind CSS, Lucide, Google Gemini (Live / Search / Maps).

## Run locally

```bash
npm install
npm run dev
```

Set a Gemini API key when prompted (AI Studio secrets or env).
